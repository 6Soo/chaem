# 🍩 챔 근무표

야간진료·오프를 자동으로 짜주는 근무표 메이커. 모바일 우선, 토스 스타일 UI.

## 배정 규칙

6명(채미·예원·영주·연진·수현·연주) 기준으로 매주 아래 규칙을 지키며 자동 배정합니다.

- **야간진료**: 월·수 각 3명씩, 전원이 매주 한 번. 같은 3인조가 굳어지지 않게 매주 조를 섞고, 개인별로 월↔수가 번갈아가도록 배정
- **주 오프**: 1인당 주 1회, 화~토. 하루 1명이 기본이고 한 요일만 2명
- **2인 오프**: 화·수는 피하고(기본: 목·금·토만 허용), 같은 페어가 반복되지 않게 로테이션
- **채미·예원 분리**: 같은 날 오프 금지, 같은 야간조 금지 (설정에서 페어 변경 가능)
- **공휴일 주간**: 오프 없음(공휴일이 쉬는 날). 월·수가 공휴일이면 그날 야간도 없음(설정으로 변경 가능)
- **수요일 오프인 사람은 수요일 야간 불가**, 일요일 휴진, 월요일 전원 출근

공평성은 **통계 탭**에서 확인할 수 있어요 (야간 요일·오프 요일·토요일 오프·2인 오프 횟수).

## 주요 기능

- 월 단위 자동 생성 + 주 단위 다시 뽑기
- 날짜를 눌러 오프/야간 **직접 수정** — 규칙에 어긋나면 경고 표시
- 날짜를 눌러 **공휴일 지정/해제** (2025~2027 한국 공휴일 내장, 참고용이니 임시공휴일 등은 직접 수정)
- **텍스트 복사**(카톡 공유용) / **이미지 저장**(PNG)
- 데이터는 브라우저(localStorage)에 저장 — 서버 없음

## 배포

push하면 GitHub Actions가 테스트 → 빌드 → `gh-pages` 브랜치로 자동 배포합니다.
사이트 주소: **https://6soo.github.io/chaem/**

`gh-pages` 브랜치가 처음 만들어질 때 GitHub이 Pages를 자동 활성화해요.
혹시 사이트가 안 뜨면 최초 1회만 **Settings → Pages → Source: Deploy from a branch → `gh-pages`**를 선택해주세요.

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm test         # 배정 알고리즘 테스트 (vitest)
npm run build    # 타입체크 + 프로덕션 빌드
```

## 구조

```
src/
  lib/
    scheduler.ts   # 핵심 배정 알고리즘 (주 단위 전수 탐색 + 이력 기반 점수화)
    holidays.ts    # 한국 공휴일 내장 데이터 + 사용자 수정
    exportText.ts  # 카톡 공유용 텍스트
    exportImage.ts # PNG 저장
    storage.ts     # localStorage 영속화
  components/      # 달력, 상세 바텀시트, 통계, 설정 등
```

배정은 한 주의 가능한 모든 야간조(≤16) × 오프 조합(≤1,680)을 점수화해 최근 8주 이력 대비
가장 덜 반복되는 조합을 고르는 방식이라, 결과가 매번 조금씩 달라지면서도 규칙은 항상 지켜집니다.
